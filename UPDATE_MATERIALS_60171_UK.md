# QuoteCraftAI: робота й матеріали, ZIP 60171

## Як оновити діючий сайт

1. Розпакуй ZIP на Mac.
2. Відкрий репозиторій QuoteCraftAI на GitHub, вкладку Code.
3. Натисни Add file → Upload files (або + → Upload files).
4. Перетягни **вміст** папки з архіву: app, components, lib, public, tests та кореневі файли. Не завантажуй сам ZIP або зовнішню папку цілком.
5. Збережи зміни (Commit changes). Якщо Vercel підключений до цієї гілки, дочекайся нового Deployment зі статусом Ready.
6. Відкрий сайт, онови сторінку. У Prices натисни «Застосувати узгоджений каталог 60171».
7. Перевір ставки, потім «Зберегти ціни». Це необхідно: збережений у твоєму акаунті старий прайс не замінюється автоматично.
8. Створи **новий** кошторис. Старі кошториси зберігають свої ставки.

На діючий GitHub/Vercel зміни з цього архіву ще не опубліковані.

## Що змінилося

- Компактний базовий каталог із 83 позицій у категоріях. Прибрано старі пакетні позиції на кшталт «фарбування кімнати за $650» з нового базового каталогу. Власні додані роботи зберігаються при застосуванні каталогу. Повне повернення заводських цін замінює весь прайс.
- Окремі «від», «до» і вибрана ціна **роботи** та **матеріалів** за одиницю.
- Збереження до існуючого user_prices.prices_data; зміни в схемі Supabase не потрібні.
- Калькулятор у нижньому меню використовує Prices. Попередня версія калькулятора з її незалежним прайсом доступна через «Попередня версія калькулятора» на Home для старої чернетки.
- У кошторисі можна позначити матеріали клієнта для кожної позиції.
- Спільні підсумки для екрана, PDF і посилання клієнту: робота, матеріали, діапазон до знижки/податку, вибрана загальна сума, депозит.
- Якщо змінено кількість після розрахунку упаковок, потрібно повторно перевірити бюджет матеріалів.
- Редагування прайсу не змінює збережені кошториси. Старі кошториси без нових полів зберігають старі суми.

## Як рахуються матеріали

Чотири стани:

- **Потрібна оцінка:** вартість невідома; не входить до підсумку, кошторис має попередження.
- **Оцінено частину комплекту:** відома частина входить до підсумку, неповнота видима на екрані, у PDF і клієнтському посиланні.
- **Повний комплект оцінено:** всі три ціни обов’язкові; нижня ≤ вибрана ≤ верхня.
- **Не потрібні:** матеріалів для цієї роботи немає.

Базові матеріали автоматично підставлені для 12 типів робіт, але позначені **частиною комплекту**. Наприклад, для унітаза $4.45 — лише кільце й болти, не унітаз. Для LVP — конкретний приклад Lifeproof, не ціна будь-якого покриття. В інших роботах потрібно вибрати конкретну модель або ввести свою оцінку.

Ціни 29 товарів у довіднику — знімок перевірки 14.09.2026 для ZIP 60171 / Brickyard #1903. У кожного товару є посилання, упаковка та примітка. Нову перевірку решти цін саме за ZIP виконати не вдалося: Home Depot повертав помилку в браузері. Довідник не є live-синхронізацією чи гарантією наявності.

Для фарбування стін: 2 шари × 10% запасу, витрата BEHR 250–400 sq ft/gal. Ґрунт KILZ 2: 1 шар × 10%, 300–400 sq ft/gal. Фарба для стелі не підміняється стіновою. Плівка, валики, стрічка й спеціальні ґрунти оцінюються додатково.

Автоматичні ставки матеріалів — **за витратою**, округлені до центів за одиницю роботи. Калькулятор упаковок у кожній позиції дозволяє замінити їх бюджетом закупівлі цілих упаковок. Спільні витратні матеріали зручно додати одним окремим рядком із нульовою роботою; не включай їх повторно у ставки інших рядків. Автоматичної спільної відомості закупівель за SKU немає.

Доставку й податок магазину довідник не включає. Поле Tax застосовує введений користувачем відсоток до загальної суми після знижки; автоматичних податкових правил не додається.

## Перевірено

- TypeScript і production build Next.js.
- Сценарії фарбування, LVP і ванної; окремі підсумки, невідомі/часткові матеріали, матеріали клієнта, діапазони, податок, знижка й депозит.
- Редактор: збереження, відмова при порожній ціні, повтор після помилки, збереження незавершених змін при фоновому оновленні, повернення базового каталогу.
- Сумісність зі старими кошторисами, JSON-збереження.

Реальний запис у твій Supabase і робота на опублікованому сайті не перевірялися: доступ до акаунта в цьому середовищі не підключений. API голосу/фото не змінено, крім підказки AI про одиниці та недопущення подвійної оплати пакетних робіт.

## Технічна перевірка

```bash
npm ci
npx tsc --noEmit
node tests/materials.cjs
node tests/catalog.cjs
npm run build
```

Для тесту React-редактора потрібен react-test-renderer, сумісний із версією React; задайте PRICE_TEST_MODULES шляхом до окремих тестових node_modules, запустіть node tests/material-editor.cjs.
