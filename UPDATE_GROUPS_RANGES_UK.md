# Категорії та діапазони цін

1. Розпакуй ZIP. У GitHub завантаж вміст папки в корінь QuoteCraftAI, Commit changes. Дочекайся Ready у Vercel.
2. Prices: пошук українською/англійською, фільтр категорій; роботи згруповані. Категорію кожної роботи можна змінити.
3. Задай «Від», «До» і «Вибрана ставка», потім «Зберегти ціни». Правило: 0 ≤ від ≤ вибрана ставка ≤ до. Скасування і повернення заводських цін збережені.
4. Старі одиночні ставки показуються як від = до. Ринкові діапазони не вигадані: перевірені попередні Chicago діапазони застосовуються окремою кнопкою, інші вводить користувач. Homewyse автоматично не імпортується.
5. New estimate → Додати роботу з каталогу: пошук, категорії, діапазони; натискання додає роботу за вибраною ставкою.
6. AI використовує вибрану ставку. У редакторі видно актуальний діапазон каталогу. Підсумок, завдаток, PDF та посилання клієнту залишаються конкретними сумами за вибраними ставками. Старі кошториси не перераховуються. Зміна одиниці вручну потребує перевірки ціни: автоматичної конвертації немає.
7. Це зміни каталогу Prices / New estimate. Окремий Calculator зі своїми ставками складності не змінений.

Перевірено: TypeScript, production build, офлайн-тести діапазонів, пошуку, сумісності та JSON-збереження. Живе збереження у твоєму акаунті перевір після публікації.
