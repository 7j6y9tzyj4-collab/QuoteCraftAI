# QuoteCraftAI — голос і фото

Це оновлення наданого проєкту, а не новий додаток.

## Що змінено

- У New estimate можна додати до 4 фото, переглянути й видалити їх перед аналізом. Фото стискаються на пристрої й надсилаються разом з описом. Вони не зберігаються в кошторисі. HEIC залежить від підтримки браузера; якщо він не відкривається, потрібен JPEG.
- Голос у New estimate використовує серверне розпізнавання на компʼютері та iPhone. Додано словник змішаних будівельних термінів: клазет, бейсмент, шуз, drywall, shower pan та інші. Один запис обмежено 90 секундами/розміром; можна додиктувати наступний фрагмент.
- AI отримує інструкції не вигадувати розміри з фото та запитувати відсутні дані. При запитаннях попередні позиції залишаються без змін. Додайте відповіді в той самий опис і повторіть генерацію.
- Явно названу в описі ціну можна перенести у позицію. Для загальної вартості роботи передбачена одна позиція з переліком включених робіт, без повторного нарахування за кожну роботу.
- Звичайні ставки беруться з існуючої бібліотеки. Опис для клієнта залишається англійською, а кошторис можна редагувати перед збереженням або друком.

## Як перевірити

1. Відкрий New estimate, додай фото ванної.
2. Надиктуй: «Зняти стару плитку, піддон душу залишити. Плитку купує клієнт. Уся робота чотири тисячі доларів».
3. Натисни Generate estimate. Перевір склад робіт, виключення та суму.
4. Для опису «Покласти плитку на підлогу» без площі очікуються запитання, а не вигадана площа.
5. Додиктуй відповіді та знову натисни Generate estimate. Генерація щоразу обробляє весь поточний опис; це ще не редагування довільного збереженого кошторису голосовими командами.

## Запуск на Mac

Розпакуй архів в окрему папку. Не видаляй свою попередню робочу копію.
У Terminal перейди до розпакованої папки й виконай:

```
npm ci
npm run dev
```

Потрібні наявні налаштування проєкту в локальному .env.local або у Vercel:
OPENAI_API_KEY, NEXT_PUBLIC_SUPABASE_URL,
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY, SUPABASE_SERVICE_ROLE_KEY.
OPENAI_MODEL необовʼязковий, поточне значення за замовчуванням — gpt-4.1-mini.
Секретних ключів в архіві немає. Використай свої поточні налаштування, не вставляй ключі в чат або репозиторій.
Після запуску відкрий http://localhost:3000. Для мікрофона на іншому пристрої потрібен HTTPS.
Цей архів сам не оновлює сайт у Vercel; для цього потрібне звичайне розгортання твого проєкту.

## Перевірено та обмеження

Пройдено TypeScript, production build з тестовими значеннями налаштувань Supabase та офлайн-тести `node tests/voice-photos.cjs`.
Тести перевіряють передачу фото, обмеження файлів, збереження уточнень і явно заданої суми; відповіді AI у тестах підставні.
Реальні виклики OpenAI, авторизацію Supabase, запис на фізичному iPhone та платіжну готовність не перевірено.
Словник не є автоматичним навчанням на голосі. Точне розуміння кожної фрази не гарантоване: переглядай транскрипцію, позиції й суми.
Фото додано тільки в New estimate; окремий Calculator зберігає наявну поведінку.
Наявні API-маршрути не мають серверної перевірки користувача/лімітів витрат. Перед відкриттям сервісу стороннім клієнтам потрібні авторизація й обмеження використання.

app/api/transcribe/route.ts, app/globals.css. Нові: lib/jobPhotos.ts,
