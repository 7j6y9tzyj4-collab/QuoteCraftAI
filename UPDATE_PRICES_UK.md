# Оновлення Prices

Базові ставки: bathroom_mirror_install_each — $75;
vanity_light_install_each та light_fixture_replace — $125.
Це узгоджені з користувачем ставки для звичайного монтажу готового дзеркала
та світильника на готовому підключенні, а не автоматична синхронізація з Homewyse.

Після завантаження цього оновлення в GitHub і успішного розгортання Vercel:
1. Відкрий Prices.
2. Натисни «Застосувати $75 / $125», щоб оновити ці три позиції у своїй
   існуючій бібліотеці. Решта твоїх ставок залишиться у формі.
3. Натисни «Зберегти ціни». Дочекайся повідомлення «Ціни збережено в акаунті».

Будь-яку ставку можна змінити вручну, потім зберегти.
«Скасувати зміни» повертає останні отримані збережені ставки.
«Повернути заводські ціни» → «Так, повернути» завантажує повну базову бібліотеку
у форму. Натисни «Зберегти ціни», щоб застосувати скидання до акаунта.
Заводська бібліотека вже містить $75/$125.

Зміна бібліотеки впливає на наступні генерації в New estimate.
Уже створені кошториси не перераховуються. Поточні $175 можна змінити
у відповідних полях Rate самого кошторису. Окремий Calculator має власний прайс.

Код для збереження пише в існуючу таблицю user_prices без зміни схеми.
За помилки запиту або таймауту форма зберігає правки для повторної спроби.
Немає запису після кожного натискання клавіші. Під час переходів між вкладками
додатка форма зберігається; при закритті/перезавантаженні вкладки з правками
браузер отримує запит показати стандартне попередження (підтримка залежить від браузера).

Перевірено: production build з тестовими налаштуваннями; компонентні тести
редагування, фонового оновлення, порожньої ставки, помилки запису та
підтвердженого скидання. Реальний запис у твій Supabase ще не перевірено.

Для запуску компонентних тестів (з папки проєкту):
npm install --prefix /tmp/quotecraft-price-test react@19.2.0 react-test-renderer@19.2.0
PRICE_TEST_MODULES=/tmp/quotecraft-price-test/node_modules node tests/prices.cjs

Основні зміни: lib/defaults.ts, components/QuoteCraftApp.tsx,
новий components/PriceEditor.tsx.
